## Summary

**Gauntlet Remastered** is a comparative technical remake of the 1985 arcade classic *Gauntlet*, engineered across three separate industry-standard game engines: **Unity**, **Unreal Engine 5**, and **Godot 4**.

Developed during an academic exchange program at **Shawnee State University (SSU)** in Ohio for the *Interactive Game Programming* curriculum, the project was designed as an empirical investigation into multi-engine architecture. It analyzes performance, toolchain ergonomics, and technical hurdles when delivering identical gameplay, enemy AI behaviors, and rendering across disparate game engines.

## Responsibilities

* **Multi-Engine Mechanics Parity:** Architected the complete arcade dungeon crawler loop identically across all three engines (C# in Unity, C++ and Blueprints in Unreal Engine 5, GDScript in Godot 4), guaranteeing consistent projectile kinematics, health decay tick rates, and collision response.
* **Enemy Spawner Logic & Swarm AI:** Built dynamic monster generator mechanics, wave pacing triggers, and performant pursuit AI capable of navigating dense corridor mazes and swarming the player without performance drops.
* **Audiovisual Integration & HUD:** Recreated the classic top-down perspective, retro 80s arcade sound synthesis, health bar countdowns, key inventory systems, and exit portals across each engine's UI and audio systems.
* **Comparative Engine Benchmarking:** Documented and evaluated build sizes, compile times, memory footprint, scripting ergonomics, and physics quirks across Unity, Unreal Engine, and Godot.

## Current Status & Reception

* **Academic Evaluation:** Successfully completed and graded with top honors for the Interactive Game Programming curriculum at Shawnee State University.
* **Public Releases:** All three engine builds are compiled, documented, and publicly available for download on [itch.io](https://hollowblink.itch.io/gautlet-remastered).
* **Technical Takeaways:** Provided critical insight into cross-engine portability and low-level engine differences, directly informing subsequent engine selection for professional production.
