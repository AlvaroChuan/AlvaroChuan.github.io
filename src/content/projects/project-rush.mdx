## Summary

**Project: Rush!** is a high-octane 3D arcade racing game developed from the ground up for the *Game Engines* course at **Universitat Jaume I (UJI)**.

Inspired by classic kart racers like *Mario Kart*, players race across 3-lap dynamic circuits, gathering speed boost collectibles, executing high-speed power-slides, and competing against intelligent rival drivers. Beyond its racing gameplay, the project served as the technical testing ground that originated my procedural Bézier mesh extrusion tool and experiments in machine learning agents.

## Responsibilities

* **Procedural Track Synthesis:** Engineered an in-engine Bézier spline mesh generation system that algorithmically computes 3D racetrack ribbons, banked turns, elevation ramps, and continuous UV mapping directly from editor curve nodes.
* **Raycast Runner Kinematics:** Developed custom arcade runner physics using wheel-suspension raycasts, tire friction vectors, drift impulse dampening, and aerodynamic airborne attitude control.
* **ML Rival Drivers:** Implemented autonomous competitor agents trained using reinforcement learning principles (Unity ML-Agents), providing adaptive racing line following, dynamic obstacle avoidance, and reactive overtaking.
* **Race System Architecture:** Built spline-based checkpoint progression, lap time tracking, real-time leaderboard positioning, item box respawn triggers, and camera trailing rigs.

## Current Status & Reception

* **Academic Excellence:** Earned the highest grade in the Game Engines course at UJI for its ambitious combination of procedural geometry generation and ML navigation.
* **Research & Commercial Offshoot:** Directly gave birth to the *Interactive Bézier-Based 2D Extrusion Tool*, which led to a peer-reviewed research paper published at Eurographics CEIG 2025 and a release on the Unity Asset Store.
* **Public Release:** Playable Windows release published on [itch.io](https://hollowblink.itch.io/project-rush).
