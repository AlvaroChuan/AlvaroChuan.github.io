## Summary

**System Scape** is a 3D space exploration and planetary survival game developed as the capstone practical project for my Bachelor's thesis at **Universitat Jaume I (UJI)**. 

Set within a dying star system on the verge of going supernova, players pilot an exploration spacecraft across procedurally generated planets, mining essential resources, upgrading ship navigation and thermal shields, and leaping from orbit to orbit to escape before the final cataclysm. The game serves as the live benchmark demonstrating real-time planetary synthesis powered by my custom 3D Wave Function Collapse tool.

## Responsibilities

* **Procedural Planet Synthesis:** Integrated the custom GPU/CPU Wave Function Collapse algorithm directly into the runtime level loading pipeline, generating unique spherical and voxelized planetary topologies on the fly with consistent biomes.
* **Spacecraft Flight Kinematics:** Programmed Newtonian spaceflight mechanics with planetary gravitational attraction, atmospheric re-entry drag, orbital transition vectors, and landing gear stabilization.
* **Resource Economy & Crafting Loop:** Designed the survival gathering loop, inventory management, fuel consumption, and ship subsystem upgrade trees required to withstand outer-system radiation.
* **Thesis Demonstration Suite:** Structured deterministic seed generation and performance telemetry tracking (frame pacing, memory consumption, collapse timings) to validate procedural generation metrics for academic evaluation.

## Current Status & Reception

* **Academic Honors:** The combined [Bachelor's Thesis](/assets/bachelor-thesis.pdf) and System Scape project were awarded the **highest possible grade and Honors (Matrícula de Honor)** at Universitat Jaume I.
* **Open Source Repository:** Complete Unity project source code and demonstration scenes published on [GitHub](https://github.com/AlvaroChuan/System-Scape).
* **Research Foundation:** Served as the practical foundation and real-time testing ground for my subsequent PhD research on algorithmic constraint satisfaction in games.
